This release lets a server that ran a newer preview build go back to 0.10 without losing its sign-in file.

## Fixed

- A server that had run a newer PSF Guard, such as the `edge` or an older
  `latest` Docker image, could refuse to start on 0.10.2 with "unknown field
  `tokens`" while loading its browser users. The newer build adds personal
  API tokens to `auth.json`. This version loads that file, keeps the fields
  it does not understand and writes them back unchanged, so users sign in
  as before and the tokens work again after an upgrade. API tokens
  themselves are not honoured by 0.10.

## Changed

- The Docker image tag `latest` now always means the newest release; `edge`
  follows the development branch. A server built from that branch calls
  itself 0.11.0 and no longer offers 0.10 as an update.
