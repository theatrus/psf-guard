# v0.11.1

PSF Guard 0.11.1 fixes stack previews missing from the desktop Sky map and
updates HTTPS certificate validation.

## Fixed

- Completed mono and colour stacks appear inside their fields in **Sky**
  when **Stacks when zoomed** is on and the map is zoomed past 3×. The
  desktop app now loads these previews from its local server.

## Security

- Backports the HTTPS certificate fixes from 0.12.1. PSF Guard no longer
  trusts certificates issued through distrusted emSign intermediates. This
  fixes [RUSTSEC-2026-0382](https://rustsec.org/advisories/RUSTSEC-2026-0382)
  and [RUSTSEC-2026-0383](https://rustsec.org/advisories/RUSTSEC-2026-0383).
- Updates the other network and archive dependencies to the fixes used in
  0.12. Image-processing libraries and stack formats are unchanged.

## Upgrading

- No catalog migration or stack rebuild is needed for this fix. Existing
  completed stacks work after upgrading.
