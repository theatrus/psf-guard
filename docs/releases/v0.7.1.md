# PSF Guard v0.7.1

Signed Windows builds. No functional changes.

The Windows installer, the MSI, the standalone CLI, and the executables
inside the installer are now Authenticode signed as **StackFoundry LLC**,
through Azure Artifact Signing. Previously they shipped unsigned, so Windows
reported "Unknown Publisher" and Microsoft Defender ran each download in a
sandbox to work out what it was.

Signing happens through Tauri's `signCommand`, which runs as each artifact is
packaged. Signing the executable beforehand does not survive: the bundler
rewrites the main binary while packaging it, leaving a signature whose digest
no longer matches — an installer that verified perfectly while the program
inside it did not.

SmartScreen may still warn on first download. Reputation is scored per file
hash and starts from zero on every build, so signing establishes a publisher
identity rather than an immediate clean pass.
