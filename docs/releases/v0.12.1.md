# v0.12.1

PSF Guard 0.12 keeps its own catalogs in sync with Target Scheduler, matches
flats by what they measure, adds stack stretches and Gaia colour calibration,
and backs up on a schedule. Direct Target Scheduler access still works in 0.12
but is deprecated.

0.12.1 is the first 0.12 release with a macOS app and automatic updates. The
0.12.0 release has Windows and Linux downloads only, and installed copies were
not offered it. Read the
[0.12.0 notes](https://github.com/theatrus/psf-guard/blob/v0.12.1/docs/releases/v0.12.0.md)
for everything new in 0.12, including the Target Scheduler deprecation and the
steps for upgrading from 0.11.

## Security

- PSF Guard no longer trusts HTTPS certificates issued through emSign
  intermediate certificates that browsers have stopped trusting. This applies
  to update checks, sync with a remote server, catalog and satellite element
  downloads, and the other connections PSF Guard makes. It fixes
  [RUSTSEC-2026-0382](https://rustsec.org/advisories/RUSTSEC-2026-0382) and
  [RUSTSEC-2026-0383](https://rustsec.org/advisories/RUSTSEC-2026-0383).

## Upgrading

- **From 0.11 or earlier:** follow the upgrade steps in the
  [0.12.0 notes](https://github.com/theatrus/psf-guard/blob/v0.12.1/docs/releases/v0.12.0.md#upgrading-from-011).
- **From 0.12.0:** nothing to do.
