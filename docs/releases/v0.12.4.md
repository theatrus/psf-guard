# v0.12.4

PSF Guard 0.12.4 starts when an image folder is missing, keeps the frame of a file renamed after it was imported, fixes flat coverage for masters with older flats, and updates zstd for four security advisories.

## Fixes

- PSF Guard starts when one of a database's image folders is missing, for
  example after you move the folder or before its drive is mounted. Before,
  the server stopped with "Image directory not found" until the folder was
  removed from the configuration by hand. Frames in a missing folder show as
  not found until the folder is back, and you can change the database's
  folders in **Settings**. Imports skip a missing folder and import the
  others. Remote image uploads to a missing folder are refused, and the
  upload setting stays on.
  ([#1019](https://github.com/theatrus/psf-guard/issues/1019))

- A file renamed after it was imported keeps its frame. Before, an
  automatic import added the renamed file as a second frame, and the first
  frame showed **Catalog only**. The frame keeps its grade and history and
  uses the new name. To clean up frames imported twice by earlier versions,
  open the database in **Settings** and click **Merge renamed lights**. PSF
  Guard copies the database first. A catalog that syncs from Target
  Scheduler, or that rigs sync their lights into, keeps the old behavior.
  See [Renamed files](https://github.com/theatrus/psf-guard/blob/v0.12.4/docs/IMPORTING.md#renamed-files).
  ([#1020](https://github.com/theatrus/psf-guard/issues/1020))

- A fresh flat that contributes to a light's master now provides coverage even
  when older flats in the same master move the median capture time beyond
  the **Flat age limit**. Age checks and the calibration report use the nearest
  contributing flat; a 1-day limit includes exactly 24 hours on either side.

- A stack page reloaded just as a processing run finished could show the
  previous result. It now shows the finished one.

- Settings no longer shows a second scrollbar when you open it from the
  Stacks page. Before, with a stack's **Exact measurements** table open,
  scrolling in Settings could also scroll the Stacks page behind it, and the
  page could be out of view when Settings closed.

## Security

- PSF Guard's zstd library is updated for memory-safety advisories in its
  stream and context handling. PSF Guard uses zstd to read and write
  compressed XISF files and saved stacking contexts, and to decompress HTTP
  responses. It fixes RUSTSEC-2026-0391, RUSTSEC-2026-0398, RUSTSEC-2026-0403
  and RUSTSEC-2026-0410.
