# v0.12.2

PSF Guard 0.12.2 fixes stack previews missing from the desktop Sky map.

## Fixed

- Completed mono and colour stacks appear inside their fields in **Sky**
  when **Stacks when zoomed** is on and the map is zoomed past 3×. The
  desktop app now loads these previews from its local server.

## Upgrading

- No catalog migration or stack rebuild is needed for this fix. Existing
  completed stacks work after upgrading.
