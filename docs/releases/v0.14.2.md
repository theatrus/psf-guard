# v0.14.2

PSF Guard 0.14.2 downloads ONNX Runtime for the Seiza noise model again, and lets you start a plan with no images and add its first rig.

**To update an installed desktop app,** click **Install update** when PSF Guard offers the update.

**You do not need to download `.app.tar.gz`, `.sig`, `updater.json` or `notice.json` yourself.** PSF Guard uses these files for update checks and automatic updates. To install PSF Guard on a Mac, download the **DMG**.

**For server or command-line use,** choose a standalone binary or the Fedora RPM. See the [server and CLI installation guide](https://psf-guard.com/docs/install.html).

Coming from 0.13 or earlier? Read the [0.14.0 release notes](https://github.com/theatrus/psf-guard/blob/v0.14.2/docs/releases/v0.14.0.md) first, including their upgrade steps.

## Fixes

- **Download both** in **Settings › Processing › Stacking** and
  `psf-guard-cli noise-model download` work again. Microsoft's GitHub
  repository for ONNX Runtime has been offline since about 18 November, so
  the download failed with a 404. PSF Guard now downloads a copy of the
  same ONNX Runtime 1.31.1 archive from its own
  [GitHub release](https://github.com/theatrus/psf-guard/releases/tag/onnxruntime-1.31.1),
  checked against the same SHA-256 as before, and tries Microsoft's address
  second. A source that stops sending for a minute no longer holds the
  download open.
  ([#1136](https://github.com/theatrus/psf-guard/pull/1136))

- You can start a plan with no images or database from **New plan** in the
  Library's toolbar or **New plan...** at the top of the header's project
  picker. **Create plan** opens the plan on **Framing** with **Object name**
  ready for the target. Before, **New plan** was only at the bottom of the
  Library, and saving left you in the list.
  ([#1135](https://github.com/theatrus/psf-guard/pull/1135))

- **Rigs** and **Framing** show an **Add objective** button for a plan with
  no objectives. A rig joins a plan by shooting its objectives, so **Add a
  rig** and the rig switches on **Framing** stay disabled until the plan
  has one; before, only a tooltip and a grey line explained why. The new
  objective starts on a band that a rig or the template library has a
  template for, so a rig can join.
  ([#1135](https://github.com/theatrus/psf-guard/pull/1135))
