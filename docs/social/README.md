# Social artwork

These text-free images use the PSF Guard shield, Airy rings, diffraction
spikes, and teal-to-violet brand colors.

| File | Use |
|---|---|
| `psf-guard-profile-1024.png` | Square profile image for social accounts |
| `psf-guard-x-header-1500x500.png` | X header at 1500 by 500 pixels |
| `psf-guard-facebook-cover-1640x624.png` | Facebook cover at 1640 by 624 pixels |
| `psf-guard-profile-master.png` | Full-resolution profile master |
| `psf-guard-banner-master.png` | Full-resolution 3:1 banner master |

The banner keeps its left side dark for a profile-photo overlap or later copy.
